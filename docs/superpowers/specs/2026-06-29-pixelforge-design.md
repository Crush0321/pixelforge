# PixelForge 设计文档

> AI 图片生成网页工具 - 设计规格说明

**项目名称**：PixelForge
**版本**：v1.0
**日期**：2026-06-29
**状态**：设计完成，待实现

---

## 1. 项目概述

### 1.1 项目定位

PixelForge 是一个基于 Web 的 AI 图片生成工具，使用 Python Flask 构建后端，提供简洁的网页界面让用户通过文字描述生成高质量图片。

### 1.2 核心目标

- 提供简洁易用的图片生成界面
- 支持硅基流动平台的多个国内 AI 模型
- 保持极简科技风的视觉设计
- 轻量级部署，个人使用友好

### 1.3 目标用户

- 内容创作者（公众号、自媒体）
- 设计师（快速原型、灵感探索）
- 开发者（测试 AI 模型能力）
- 个人用户（创意图片生成）

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 图片生成

- **提示词输入**：支持中英文提示词，文本框支持多行输入
- **模型选择**：下拉菜单选择可用的 AI 模型
- **参数配置**：
  - 图片尺寸：预设选项（1024x576, 1024x1024, 576x1024 等）
  - 推理步数：滑块选择（15-30 步）
  - 随机种子：可选输入（留空则随机）
- **生成按钮**：触发图片生成，显示加载动画

#### 2.1.2 结果展示

- **图片预览**：大图展示生成结果
- **生成信息**：显示模型、生成时间、种子值
- **操作按钮**：下载图片、重新生成、微调提示词

#### 2.1.3 历史记录

- **记录保存**：自动保存最近 20 条生成记录
- **缩略图列表**：网格展示历史图片
- **查看详情**：点击可查看完整信息
- **清空功能**：一键清空所有历史

#### 2.1.4 模型管理

- **模型列表**：显示所有可用模型
- **状态检测**：自动检测模型可用性
- **模型描述**：显示模型特点和推荐场景

### 2.2 支持的模型

| 模型 ID | 名称 | 提供商 | 特点 |
|---------|------|--------|------|
| `Tongyi-MAI/Z-Image-Turbo` | Z-Image Turbo | 通义 | 快速生成，性价比高 |
| `Tongyi-MAI/Z-Image` | Z-Image | 通义 | 标准版，效果稳定 |
| `baidu/ERNIE-Image-Turbo` | ERNIE Image Turbo | 百度 | 快速生成 |
| `Qwen/Qwen-Image-Edit-2509` | Qwen Image Edit 2509 | 通义千问 | 图片编辑（新版） |
| `Qwen/Qwen-Image-Edit` | Qwen Image Edit | 通义千问 | 图片编辑 |
| `Qwen/Qwen-Image` | Qwen Image | 通义千问 | 图片生成 |
| `Kwai-Kolors/Kolors` | Kolors | 快手 | 中文理解强，公众号封面推荐 |

```
┌─────────────────────────────────────────────────────────────┐
│                      用户浏览器                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  HTML + Tailwind CSS + JavaScript                   │   │
│  │  - 提示词输入                                        │   │
│  │  - 模型选择                                          │   │
│  │  - 结果展示                                          │   │
│  │  - 历史记录                                          │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                           │
                           │ HTTP 请求
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                    Flask 后端服务                            │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  app.py - 路由处理                                   │   │

│  │  ├── 调用硅基流动 API                                │   │
│  │  ├── 处理异步任务                                    │   │
│  │  └── 下载保存图片                                    │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                           │
                           │ API 调用
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                   硅基流动 API                               │
│  https://api.siliconflow.cn/v1/images/generations           │
```

### 3.2 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端样式** | Tailwind CSS (CDN) | 原子化 CSS 框架 |

## 4. API 接口设计

### 4.1 生成图片

**请求**
```
POST /api/generate
Content-Type: application/json
```

**请求体**
```json
{
  "prompt": "一只可爱的猫咪坐在窗台上",
  "model": "Kwai-Kolors/Kolors",
  "size": "1024x576",
  "steps": 25,
  "seed": null
}
```

**成功响应**
```json
{
  "success": true,
  "data": {
    "image_url": "/static/images/generated/generated_20260629_123456.png",
    "filename": "generated_20260629_123456.png",
    "model": "Kwai-Kolors/Kolors",
    "prompt": "一只可爱的猫咪坐在窗台上",
    "size": "1024x576",
    "steps": 25,
    "seed": 123456,
    "generation_time": 3.2
  }
}
```

**错误响应**
```json
{
  "success": false,
  "error": "生成失败：API 密钥无效"
}
```

### 4.2 获取模型列表

**请求**
```
GET /api/models
```

**响应**
```json
{
  "models": [
    {
      "id": "Kwai-Kolors/Kolors",
      "name": "Kolors",
      "provider": "快手",
      "description": "中文理解强，适合公众号封面",
      "available": true
    }
  ]
}
```

### 4.3 获取历史记录

**请求**
```
GET /api/history
```

**响应**
```json
{
  "records": [
    {
      "id": "uuid-xxxx",
      "prompt": "一只可爱的猫咪",
      "model": "Kwai-Kolors/Kolors",
      "image_filename": "generated_20260629_123456.png",
      "image_url": "/static/images/generated/generated_20260629_123456.png",
      "generation_time": 3.2,
      "created_at": "2026-06-29T12:34:56Z"
    }
  ],
  "total": 15
}
```

### 4.4 清空历史记录

**请求**
```
DELETE /api/history
```

**响应**
```json
{
  "success": true,
  "message": "历史记录已清空"
}
```

## 7. 错误处理

### 7.1 错误类型与处理

| 错误类型 | 触发条件 | 用户提示 | 处理方式 |
|----------|----------|----------|----------|
| API 密钥无效 | `.env` 配置错误 | "请配置有效的 API 密钥" | 引导查看 README |
| 模型不可用 | 模型下线或维护 | "该模型暂时不可用" | 自动切换模型 |
| 生成超时 | 超过 60 秒 | "生成超时，请重试" | 提供重试按钮 |
| 网络错误 | 请求失败 | "网络连接失败" | 检查网络提示 |
| 提示词违规 | 内容安全过滤 | "提示词包含违规内容" | 建议修改提示词 |
| 余额不足 | 账户额度用完 | "账户余额不足" | 引导充值 |

### 7.2 前端错误展示

```javascript
// Toast 提示样式
{
  type: 'error',      // success | error | warning | info
  message: '错误信息',
  duration: 3000      // 显示时长（毫秒）
}
```
